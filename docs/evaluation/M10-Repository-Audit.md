## Historical M5 measurements

The M5 runner processed simple HTML and CSV with four concurrent Jobs in each of three waves. Each wave waited for terminal detection, detail reads and idempotency replay before launching the next. The report gives one 12-Job trial per topology with end-to-end rates of 4.30 and 4.40 Jobs/s. Median creation-to-dispatch was 870.80 and 864.23 ms, while median execution was 10.37 and 10.58 ms. The observed gap is consistent with the one-second poll and wave barriers. M5 collected a load sample under service memory limits, which is insufficient to establish CPU saturation. M10 uses new workload definitions and measurement boundaries and reports them independently. [M5 results](M5-core-evaluation-results.md)
