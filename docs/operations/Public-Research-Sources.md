# Public research sources

Harbourline searches two public collections in both the isolated demo and company workspace. Wikidata supplies identity descriptions. Wikimedia Commons supplies credited historical works. The company intelligence catalog separately requires a current grant for commercial evidence and a valid quote for a priced plan.

## What the search can establish

A creator result links each matched work to a named credited account, recorded creation date, archive page and specific revision. When the archive names the original Flickr or 500px work and its author profile, both links accompany the archive link. The original publication and its archive copy count as one work. Names alone never join accounts. The date describes the work and does not imply recent activity.

Food searches accept dated descriptions containing evidence of food or dining. For an unspecified affordable-dining query, the initial working threshold is a historical item price of HK$50 or less, or an explicit low-cost description. A query such as “meals under HK$33” uses the stated ceiling. Receiving a low-cost creator result does not establish a present menu price. Distinct matching dates determine the first sort key. When the verified Granite multilingual model is available it orders the eligible works by similarity and breaks creator ties using the strongest matching work. The latest matching date orders remaining ties. With no model, the latest matching date breaks ties directly. Related identity descriptions cannot enter this result set.

Examples include a priced dish documented by N509FZ in Sham Shui Po in 2018, a 2012 delivery minimum in See-ming Lee’s archived Flickr description and a 2016 Causeway Bay street snack described as inexpensive by Ilya Yakubovich on 500px. A menu photographed by JamezKinaLoon V802 in Yau Tsim Mong on 26 September 2024 shows six octopus balls for HK$25 and eight for HK$30. Its linked bilingual transcription is separate from the published description and only attaches when the account, file ID and media digest match. [2018 dish](https://commons.wikimedia.org/?curid=96222071), [2012 delivery menu](https://commons.wikimedia.org/?curid=97594989), [2016 snack vendor](https://commons.wikimedia.org/?curid=73623226), [2024 photographed menu](https://commons.wikimedia.org/?curid=153237769)

## Acquisition and attribution

The Commons action API discovers works from a bounded set of Hong Kong queries and rechecks a set of reviewed file IDs. Successful publication requires a dated image, an identifiable credited account and an applicable CC0, CC BY or CC BY-SA license. The collector screens deletion, missing-permission and other recognized warning templates and restrictions. For local works it requires the archive to attribute the image as the credited account's own work. For imported works it requires both an original item and a matched publishing-platform account in the file metadata. A link can outlive the original platform page.

Each result includes media license, attribution, source description, source revision, and Core Record and Evidence references. Published descriptions come from Commons file-page text under CC BY-SA 4.0. Markup is stripped, long excerpts are abbreviated and contact details are excluded where detected. Preserve the credit, source revision, original link and relevant license links when displaying or exporting an excerpt. Label edits or translations and preserve applicable share-alike terms. Display thumbnails only when the returned URL is present, with the adjacent photographer credit and media license. Archive hosting or an image reuse grant supplies no endorsement or likeness release. [Commons licensing](https://commons.wikimedia.org/wiki/Commons:Licensing), [reuse guidance](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

For a bounded subset of works, the Wikimedia Analytics API supplies file-description-page views for the prior complete calendar month, all access methods, user traffic. The displayed month and query URL accompany every count. Zero is a measured zero. Missing observations remain unavailable. These measurements apply to the archive page, not the source creator’s audience. They have no role in ranking or campaign forecasts. [Analytics access and CC0 license](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/documentation/access-policy.html), [definition of a page view](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/concepts/page-views.html)

## Operations

Both Harbourline Windows launchers install the two release-pinned mappings after the API starts. Each feed has a separate registered Source and configuration, a passing validation report, a recorded release-launcher approver and a normal Core collection job. A fresh dated bundled capture can initialize the feed. Expired bundles require a live check. The scheduler checks active feeds daily. Existing withdrawals, blocked feeds and retired mappings retain their operator decisions on startup.

The normal Data Operations controls can prepare, validate, approve and withdraw either feed. Operators can also invoke `python -m backend.intelligence.install_public_research` inside the owned API container to repair an interrupted first install. Pending collections must finish through the worker before their records appear. The works feed briefly holds its prior publication when validating a replacement to avoid exposing newly removed works. A publication expires seven days after its source observation. Explicit access blocks hide the feed and require operator review. Transient publication errors retain only still-current, previously authorized evidence when no change has been observed. Withdrawing the source immediately blocks customer reads. Core collection evidence is retained in the installation’s existing audit storage.

Customer search paths are `/api/v1/marketing/intelligence/public-research/works` on the isolated public demo and `/api/v1/marketing/intelligence/partner/public-works` in the company workspace. Both accept a `q` query. The operator lifecycle uses `/api/v1/marketing/intelligence/operator/public-works/` with `status`, `prepare`, `approve` and `withdraw`.

## Evidence that requires a separate grant

A current advertiser quote needs creator or representative authorization, named deliverables, currency, terms and validity dates. Audience demographics, commercial response and campaign outcomes require an appropriately scoped creator or partner feed. These fields stay unavailable in public-research results. Flickr's commercial API requires prior arrangement. YouTube Analytics channel and content-owner reports require owner authorization. This integration calls neither upstream for commercial measurement. A linked historical Flickr or 500px attribution is archival provenance and does not authorize a separate collection on that platform. [Flickr API access](https://www.flickr.com/services/api/), [YouTube reporting authorization](https://developers.google.com/youtube/reporting/v1/reports)


## Current market publications

The Windows launcher installs the approved publisher feeds. The dispatcher retrieves them over HTTPS and creates ordinary collection jobs. Each Core receipt has a source, mapping, evidence record and validation result. A source becomes searchable after all its batches pass. The operator can see collection progress, review the receipt, withdraw the source or request a refresh under **Operations → Market sources**.

| --- | --- | --- |

TVmaze metadata and adapted excerpts retain CC BY-SA 4.0 attribution. [API license](https://www.tvmaze.com/api#licensing) |

A series host has a credited series role. Where an episode has no synopsis, its source card identifies the excerpt as a series description. A dated Hong Kong publication establishes topic coverage. Contributor residence, audience demographics, audience reach, commercial availability and fees each need independent evidence. A query requiring affordable dining can display related credited food presenters in a separate result when price evidence is missing.

The two incremental feeds check publisher modifications every six hours and reconcile the complete eligible scope daily. Smaller feeds receive a complete check each cycle. The service expires records after 48 hours, keeps up to 90 days of eligible measurement history and immediately hides a withdrawn source. A complete reconciliation also removes works that have left the eligible scope. Explicit publisher access denial requires review. Rate-limit and transient failures back off. A manual refresh accepts the same backoff and a 15-minute minimum interval after success. Validation occurs on a live sample before the first publication or explicit restoration.

The customer endpoints under `/api/v1/marketing/intelligence/{mode}/market/` expose `overview`, `creators`, `creators/{id}` and `activity`. Company reads use the existing customer boundary. An isolated public-research-enabled installation also permits the demo mode. The overview's 12 buckets count publication dates in Hong Kong time across the currently eligible catalog. A measured work has at least one supplied source counter, including a reported zero.

Operators can read `/api/v1/marketing/intelligence/operator/market/sources` and use `POST` on `{key}/refresh`, `{key}/withdraw` or `{key}/restore` beneath that route. `python -m backend.intelligence.install_public_research` installs missing mappings and preserves earlier operator decisions.
