Harbourline · Local setup for Windows

Extract the complete project into a writable local NTFS folder.

Open Start-Harbourline-Demo.bat to research Hong Kong creators without an account.
Choose Search public directory. Open a matching contributor to inspect dated evidence.
Save two contributors to compare published works and export a brief from Research shortlist.
The separate fictional campaign practice area includes sample creator quotes.
Open Start-Harbourline-Pilot.bat for saved company campaigns. Sign in with an account from your administrator.
First-time visitors can choose Try the demo without an account. Operators can choose Operator setup to create a company.
The launcher prints the local URL and initial access instructions.

Start-FYP-Demo.bat opens the separate Core teaching demonstration.
Start-Platform.bat opens the general-purpose collection platform.

Use a Windows 11 x64 workstation with hardware virtualization, WSL 2,
Docker Desktop, a browser, disk space and first-run internet access.
If Windows requires a restart during setup, run the launcher again.
Host Node.js and Python are optional developer tools.

Stop-Platform.bat -Demo and Stop-Platform.bat -Pilot retain their respective
data volumes. Diagnose-Platform.bat accepts the same mode switches.
See README.md for settings, credentials, operating limits and troubleshooting.
